# 策略例外登记站（Policy Exception Registry）

Kotlin/JVM 实现的策略例外登记与解释服务：管理策略版本、条款级临时例外、双审核激活、
到期/撤销状态机、基于事实的策略结论解释、版本链/审计链浏览，以及可重建实例的导出导入。

## 构建与演示

```bash
# 构建前检查
./gradlew classes

# 测试 + 启动演示
./gradlew test
./gradlew run --args='--host 127.0.0.1 --port 5227'
```

打开 http://127.0.0.1:5227 ，页面标题为“策略例外登记站”。

> Wrapper 需要本机 JDK。若系统 `java` 不可用，可指定 `JAVA_HOME`，例如：
> `JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home ./gradlew classes`

## 核心规则

- **条款级放宽**：例外必须明确勾选要偏离的条款；不存在可以跳过整个策略的例外。
- **双审核激活**：pending → 两名与提交者不同的审核者依次确认 → active；提交者不能审核自己；
  同一审核者重复确认不增加计数。
- **服务端 UTC**：所有判定以服务端 UTC 时钟为准；`validUntil` 结束瞬间即失效（区间左闭右开）。
- **撤销与到期不改写历史**：撤销自 `revokedAt` 生效，到期由状态扫描转换为 expired；
  在过去生效点上重放事实仍能复现当时的“正常命中 vs 例外放行”解释与决策指纹。
- **续期即新版本**：续期不能原地延长；旧版本标记 superseded，新版本 pending 并通过
  `renewedFrom` 指向旧版本，同属一条 `chainId` 链。
- **并发裁决**：激活/撤销/续期均携带 `statusRevision`；陈旧请求得到 409 版本冲突，
  但仍留下一条不含任何证明材料的失败审计事件。
- **证明材料**：只长期保存摘要；文件本体存于本地 blob 目录，删除 blob 后历史页仍保留摘要与哈希。
- **范围样例**：对象表达式命中对象过多（>5）时展示按对象 ID 排序的稳定样例并给出交集过大的警告。
- **导出重建**：导出 `instance.zip`（state.json + 存活 blob），导入即整体替换实例；
  重建后状态转换、决策指纹（规范化输入的 SHA-256）与审计序号顺序一致。

## 页面

- `/` 总览；`/policies` 策略版本与编辑；`/exceptions` 例外提交（含范围预览）与详情
- `/directory` 对象目录（事实来源）；`/decide` 输入事实并查看分开的命中/放行解释
- `/audit` 策略版本链、例外版本链、决策记录、严格有序的审计链
- `/clock` 冻结/推进/恢复 UTC 时钟以模拟到期；`/bundle` 导出与重建

## 持久化布局

- `data/state.json`：单一 JSON 文档，原子写入（tmp + move），含时钟设置与全部审计/决策记录
- `blobs/<blobId>.bin`：证明材料文件本体；删除仅移除文件，state 中保留 tombstone 与摘要

## 测试

`./gradlew test`（27 个用例）覆盖：条款级放宽、自审拒绝、重复确认、区间结束端点、
撤销与历史决策保留、续期版本链、并发版本冲突审计、blob 删除保留摘要、时钟推进到期，
以及导出重建的指纹/状态/审计顺序一致性。
