# 策略例外登记站 (Policy Exception Registry)

安全运营团队的策略例外登记与裁决服务：策略版本化、例外条款级放宽、双人依次审核、
UTC 区间判定、撤销/续期工作流、事实决策的“正常命中 vs 例外放行”分离解释，
文件型持久化、哈希审计链与导出重建。

## 运行

```bash
# 构建前检查
./gradlew classes

# 测试
./gradlew test

# 演示启动（首次启动自动写入一套演示策略/目录/例外）
./gradlew run --args='--host 127.0.0.1 --port 5227'
# 打开 http://127.0.0.1:5227
```

可选参数：`--data ./data`（文件存储目录，默认 `data`）。

## 关键规则

- **条款级放宽**：例外必须显式列出偏离的条款；禁止放宽策略全部条款（不能跳过整个策略）。
- **双人审核**：`pending → active` 需要两名不同审核者依次确认；提交者不能审核自己；
  同一人重复确认返回 409 且不增加计数。
- **UTC 半开区间**：所有时刻按服务端 UTC 判定，例外在 `[startAt, endAt)` 内可用，
  结束瞬间立即失效。存储状态只有 pending/active/revoked，scheduled/expired 为按观察时刻派生。
- **撤销与历史**：撤销/到期只影响之后的决策；决策记录（含指纹）不可变。
- **续期**：必须在同一 chainId 上创建新版本（versionNo+1、renewedFrom 指针），
  旧版本区间不可原地延长，新版本重新走双审。
- **并发裁决**：所有写操作携带 `rev` 乐观锁；版本不匹配返回 409，失败请求也写入审计链，
  审计仅记录类型/原因，不含证明材料正文。
- **证明材料**：只存摘要（随记录永久保留）与本地内容寻址 blob；blob 可单独删除，
  删除后历史继续显示摘要但无法下载正文。
- **范围分析**：对对象表达式与目录求交集，交集过大时给出告警与确定性稳定样例。
- **导出重建**：`GET /api/export` 下载 zip；解压到空目录以 `--data` 指向即可重建，
  状态、决策指纹与审计链顺序保持一致。

## 页面

- 策略：编辑策略（保存即新版本）、浏览版本与条款谓词
- 例外：提交、范围预览、双审、撤销、续期；列表支持观察时钟查看 scheduled/expired
- 事实决策：输入事实 JSON 与模拟时刻，分栏展示 ①正常命中 ②例外放行/未采纳原因 ③仍违规条款
- 版本链：例外 chain 与策略版本链
- 审计链：append-only 哈希链，含成功/失败事件与链校验结果
- 目录：适用对象维护
- 数据：导出 zip、blob 删除

## 技术说明

Kotlin 2.0.21 / JDK 17，JDK 内置 `com.sun.net.httpserver.HttpServer`，零第三方运行时依赖
（JSON、表达式、SHA-256、zip 均为标准库实现）。持久化为 `data/` 下的 JSON 文件
（原子 tmp+move 写入）与 `data/blobs/` 下的内容寻址 blob。

## 测试覆盖

`src/test/kotlin/registry/RegistryTest.kt`（15 个用例）：条款级放宽、全条款拒绝、
自审拒绝、重复确认、结束端点、撤销与历史不变、续期新版本、并发冲突（审核/续期）、
blob 删除保留摘要、时钟推进派生状态、范围稳定样例、导出重建指纹/审计一致、
区间结束后禁止激活、策略版本绑定。
